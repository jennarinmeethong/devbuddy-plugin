---
description: Generate a handover for work somebody else is picking up
argument-hint: [the work item or project being handed over]
---

Prepare a handover for `$ARGUMENTS`.

1. `generate_handover` for the work item, which assembles what is recorded.
2. `find_open_questions` for what was never settled.
3. `find_missing_evidence` for claims nothing backs up.

Report remaining work, open questions, cautions, and next steps. Be specific about what is
*unknown* — the value of a handover is mostly in the parts nobody wrote down, and "this is not
recorded anywhere" is a more useful sentence than a confident guess.

Offer to draft a `Handover` record if there is anything worth keeping. Do not create one
unasked.
