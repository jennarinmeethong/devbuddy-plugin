---
description: Search what the team already decided, before working it out again
argument-hint: [what you are trying to find out]
---

Search DevBuddy for `$ARGUMENTS`.

Use `list_projects` first if you do not already know which project applies — only projects whose
owner has enabled AI access appear there, and a project that is absent is a decision rather than
an error.

Then `search_knowledge`, and `get_record` for anything that looks like it answers the question.
Read the provenance on what you find: a decision from eighteen months ago with no evidence behind
it is worth less than a recent one that cites the commit it came from.

Report what the team already decided and where it is recorded. If nothing matches, say so plainly
rather than filling the gap with your own reasoning — an unrecorded answer that looks recorded is
the problem this system exists to prevent.
